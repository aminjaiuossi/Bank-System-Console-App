# 🏦 Bank System - C++ OOP Console Application

## 📌 Overview
This is a console-based Bank Management System developed using C++ and Object-Oriented Programming (OOP) principles.  
The system simulates real banking operations such as managing clients, users, transactions, and currency exchange.

---

## ⚙️ Features

### 👤 Client Management
- Add new clients
- Update client information
- Delete clients
- Search for clients
- Display client list

### 💰 Transactions
- Deposit money
- Withdraw money
- Transfer between clients
- View transfer logs

### 👥 User Management
- Add new users
- Update users
- Delete users
- Manage system access permissions
- Login system

### 💱 Currency System
- Currency exchange features
- Manage currency rates

---

## 🧱 Project Structure

The project is built using a modular OOP structure:

- `clsBankClient` → Client logic
- `clsUser` → User management
- `clsScreen` → Base screen system
- `clsTransaction` → Banking operations
- `clsCurrency` → Currency operations
- `Global.h` → Global settings and shared data

---

## 🗂 Data Storage
Data is stored using simple text files:

- Clients.txt
- Users.txt
- TransfersLog.txt
- LoginRegister.txt
- Currencies.txt

---

## 🛠 Technologies Used
- C++
- Object-Oriented Programming (OOP)
